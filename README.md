## 🚀 Featured Projects

### 🕌 Khaleek Momen — Quran & Radio

A daily Islamic companion app, **live on Google Play**. Accurate prayer times with adhan and
pre-prayer reminders, Quran audio recitations from top reciters, live Islamic radio, morning /
evening azkar with a wird counter, and a qibla compass with a precise angle. Fully bilingual —
adapts to the device language automatically.
